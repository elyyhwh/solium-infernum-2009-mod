== INSTALLATION AND USE ==

1. Make backs up of the following files from the folder where your Solium Infernum is installed:
* GameEngine.cxt in the main game folder;
* legion.txt in the GameData > KeyData folder.

2. Replace the files in the installation folder with the files from this archive.

3. It's STRONGLY recommended to launch a new session (single player or multiplayer) to try out changes in the gameplay. You can load save files made in the unmodded game, but saving over them may lead to unpredictable bugs (not tested).

4. To revert the changes, copy the back-up files into the corresponding folders, and launch a new game or load one of the save files made in the unmodded game.

== LIST OF CHANGES ==
* Added a new ability - Chasm Walk - that allows a Legion to move through chasm cantons (such cantons can't be captured). Available only to the Starting Legions during their creation at the start of the game. Can't be offered on a level-up.
* Added 4 new epithets for the Starting Legions - 'Spawn of', 'Apostles of', 'Zealots of', and 'Paragons of'.
